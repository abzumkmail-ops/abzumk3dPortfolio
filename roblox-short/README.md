# Nubi Shorts: "In This World, Everyone Has A Like Counter"

An original, fully code-animated vertical Short (1080×1920, 60 fps, ~54 s). There are no AI images. Every character, background, UI element, sound effect and music note is generated by the code in `project/`, and every frame is reproducible.

## What's here

| Path | What it is |
|---|---|
| `final_video.mp4` | The finished Short: H.264 CRF 17, yuv420p, AAC 192 kb/s, −14 LUFS |
| `script.md` | Final narration (exact text sent to the voice engine) |
| `storyboard.md` | Shot-by-shot plan with real timings, actions, cameras, transitions and SFX |
| `contact_sheets/` | QA sheets: full-video contact sheet, character cast, expressions, poses/views |
| `reference_analysis/` | Analysis of the reference video (frames from it are kept local, not committed) |
| `project/` | The editable source project (below) |
| `archive/` | Rejected earlier story drafts |

## The voice (read this)

`final_video.mp4` uses a **free, offline placeholder voice**: Kokoro TTS with a male/female style blend, pitched up 4 semitones, which also gives about 1.26x speed. ElevenLabs only allows the "Valf" library voice through its API on paid plans. To use Valf on the free plan:

1. On elevenlabs.io, go to Text to Speech and pick the voice **Valf - Anime Protagonist Charismatic**. It's already in My Voices. Use Multilingual v2, speed 1.0.
2. Paste the lines from `project/data/script_lines.json` (or `script.md`), one per line. This costs about 1,100 credits.
3. Download the MP3, put it in `project/`, and run:

```bash
cd roblox-short/project && ./build.sh valf.mp3
```

The narration is sped up 1.25x and re-aligned word by word with faster-whisper. Every shot, caption, mouth movement and sound cue then re-times itself automatically.

## Rebuild / preview

```bash
cd roblox-short/project
PREVIEW=1 ./build.sh        # 540×960 @30 fps in about 2 min → out/preview.mp4
./build.sh                  # 1080×1920 @60 fps in about 4 min → out/final_video.mp4
```

You can also open `project/index.html?play=1` in a browser to watch the animation live (no audio), or `index.html?t=31.5` to inspect one frame.

You need Python 3 with `numpy scipy soundfile librosa faster-whisper` (plus `kokoro-onnx` for the placeholder voice), Node with Playwright and Chromium, and ffmpeg.
The Kokoro model files (`kokoro-v1.0.onnx`, `voices-v1.0.bin`) go in `project/audio/tts_models/`. They're too large for git; download them from the kokoro-onnx GitHub releases.

## How the engine works

- **Deterministic renderer** (`js/main.js`). The page exposes:
  - `window.seek(t)`: draws the frame at time `t`.
  - `window.READY`: set once the fonts and data are loaded.
  - `window.END`: the duration.
  - `window.EV`: narration lines, shot cuts, SFX cues and music cues.

  Nothing depends on playback order. Blinks, particles and dance cycles are all pure functions of time.
- **Render** (`tools/render.js`). Four headless Chromium pages each seek through their own frame range and pipe PNGs into ffmpeg. The resulting segments are joined with a stream copy.
- **Audio** (`tools/make_audio.py`). It synthesizes 37 SFX and a 5-mood score (main, tense, calm, party, love), ducks the music under the voice, and mixes the SFX at the times in `data/ev.json`.

| File | Contents |
|---|---|
| `js/core.js` | Easing, springs, seeded RNG, keyframe `track()`, drawing helpers, word-time lookup (`wordT`, `lineT`) |
| `js/characters.js` | **Reusable rig**. One skeleton (head, torso, 2 arms + separate hands, 2 legs, hair front/back layers, eyes, brows, mouth) with stable pivots. `CAST` holds per-character style data. Front, ¾, side and back views. 17 expressions, 15 mouth shapes, jittered blinking, lip-sync from word timings, and actions: `idle`, `talk`, `walk`, `run`, `celebrate`, `surprise`, `laugh`, `anticipate`. Also a dog rig. |
| `js/env.js` | Layered vector sets with parallax: hallway, concert, backyard, kitchen/cafeteria, gym/school dance, burst and soft-heart backdrops |
| `js/fx_ui.js` | Particles (confetti, hearts, stars, dust, candy, sparkles), the **like-counter badge**, goal HUD, subscribe button, stamps and pop text, word-synced captions (Lilita One, 1–3 words, colored emphasis, pop-in) |
| `js/timeline.js` | **The story**. 28 shots, each anchored to a narration word, with camera, actions, expressions and SFX |

## Making the next Short with the same cast

1. Write new lines in `data/script_lines.json`.
2. Run `python3 tools/make_voice.py` (or `--external your.mp3`) to get `data/words.json`.
3. Replace the shots in `js/timeline.js`. Copy a similar shot and anchor it to new words with `wordT('L5','cookies')`.
4. Check frames quickly with `node tools/contact.js out.png 24 300`, which renders 24 evenly spaced frames.
5. Run `./build.sh`.

To add a character, add an entry to `CAST` (skin, shirt, pants, shoes, hair style and color). If it needs a new hairstyle, add a case in `drawHair()`.
`sheet.html?mode=cast|expr|poses` renders the QA sheets for the whole cast.
